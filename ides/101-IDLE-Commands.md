# 101 IDLE Commands

Python’s built-in IDE — zero install, works everywhere.

### Editor Shortcuts
| Action                  | Windows/Linux       | macOS              |
|-------------------------|---------------------|--------------------|
| New / Open / Save       | Ctrl+N / O / S      | ⌘+N / O / S        |
| Run module              | F5                  | F5                 |
| Comment / Uncomment     | Alt+3 / Alt+4       | Option+3 / 4       |
| Indent / Dedent block   | Ctrl+] / [          | ⌘+] / [            |

 Shell Shortcuts
| Action                  | Shortcut            |
|-------------------------|---------------------|
| Previous command        | Alt+P               |
| Next command            | Alt+N               |
| Interrupt               | Ctrl+C              |

Pro Tip: IDLE is always there when you type `python -m idlelib` — perfect for quick tests.
