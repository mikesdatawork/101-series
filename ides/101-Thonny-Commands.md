# 101 Thonny Commands

Thonny — the friendliest Python IDE for beginners and educators.

### Core Shortcuts
| Action                 | Windows/Linux       | macOS              |
|------------------------|---------------------|--------------------|
| Run / Restart          | F5                  | F5                 |
| Step Over              | F6                  | F6                 |
| Step Into              | F7                  | F7                 |
| Step Out               | F8                  | F8                 |
| Stop                   | Ctrl+F2             | ⌘+F2               |
| New / Open / Save      | Ctrl+N/O/S          | ⌘+N/O/S            |
| Comment line           | Ctrl+/              | ⌘+/                |

### Debugger Superpowers
- Variables pane shows **everything** automatically  
- Hover any expression during debugging → instant value  
- “Simple mode” off → full object tree (lists, dicts, classes)

### Pro Tip
Thonny’s step-by-step visual debugger is the best learning tool on the planet.
