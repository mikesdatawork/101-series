# 101 Thonny Commands

Thonny is the beginner-friendly Python IDE that comes with its own debugger and variable viewer.

### 1. Core Shortcuts
| Action                        | Windows/Linux          | macOS                  |
|-------------------------------|------------------------|------------------------|
| Run / Restart                 | F5                     | F5                     |
| Step Over                     | F6                     | F6                     |
| Step Into                     | F7                     | F7                     |
| Step Out                      | F8                     | F8                     |
| Stop                          | Ctrl+F2                | ⌘+F2                   |
| New file                      | Ctrl+N                 | ⌘+N                    |
| Open                          | Ctrl+O                 | ⌘+O                    |
| Save                          | Ctrl+S                 | ⌘+S                    |
| Comment / Uncomment           | Ctrl+/                 | ⌘+/                    |

### 2. Debugger & Variables (Thonny’s Superpower)
| Feature                       | How to Use                                    |
|-------------------------------|-----------------------------------------------|
| Simple mode ↔ Full mode       | View → Variables (toggle)                     |
| Expression evaluation         | Hover any variable during debugging           |
| Step through code visually    | F6 / F7 – arrows show execution flow          |
| See object contents live      | Variables pane shows everything automatically |

### Pro Tips
- Thonny shows you **exactly** where your code is at every step
- Turn off “Simple mode” → instant access to full variable tree
- Use **Step Into** on your own functions — best learning tool ever
- No need for print() — everything is visible in the Variables pane
