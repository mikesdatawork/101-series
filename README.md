## Contribution Guide
Want to add a new sheet? Follow these rules:
1. Filename: `101-YourTool-Commands.md` or `101-YourTopic-Concepts.md`
2. Use clean vertical tables (no backticks in cells)
3. Include: Overview → Target Audience → 15+ categories → Tips → Resources → Mini-Glossary
4. Submit via PR with a pasteable bash script (see existing adds)

See [CHEATSHEET-CREATION-GUIDE.md](CHEATSHEET-CREATION-GUIDE.md) for the exact template.
